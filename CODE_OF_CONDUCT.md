# Code of conduct

We want this project to be a welcoming and productive place to contribute.

## Expectations

- **Be respectful and constructive.** Disagree on substance, not on people. Assume good faith.
- **Keep contributions on-topic.** This repo is a marketplace of skills for Claude Code and Codex.
  Discussion that isn't about the skills, the tooling, or how to improve them belongs elsewhere.
- **Don't engage in behavior that targets, demeans, or excludes others.** This includes — but isn't
  limited to — personal attacks, identity-based put-downs, doxxing, and unwelcome attention.
  Maintainers will remove such comments and may block repeat offenders without warning.

For the full text of the standard we follow, see the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The
expectations above are a summary; the Covenant is the canonical reference.

## Reporting

If you experience or witness behavior that violates this code, email **conduct@fencer.dev**. Reports
go to Fencer's people team and are kept confidential. We'll acknowledge receipt within two business
days and tell you the outcome.

For security vulnerabilities (not conduct issues), see [SECURITY.md](SECURITY.md).

## Scope

This code applies to all project spaces — issues, pull requests, discussions, and any synchronous
channels we run for the project — and to behavior outside those spaces when it affects the project
or its contributors.
